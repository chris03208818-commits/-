# 英文學習

我想學：英文聽力與會話，能的話閱讀與寫作也加強

我以前卡在：時間不知道怎麼安排，要學的東西太多

我現在的程度，以及我怎麼測的：大概多益450，是線上測驗算出來的

5 週後我要做到：建立起自己的讀英文習慣、找到讀書方法，進而持續學習，希望多少能在這段時間把過往所缺乏的單字詞彙、常用片語、主要文法熟悉

我練習的場景、時間和每週次數：居多是通勤時以聆聽的方式可能加上一些口說練習，每天大概一小時，假日或空閒時可以做調整及整理

那個時候我有空的感官：耳朵跟嘴巴

我的產品會怎麼幫我：幫我整理可聆聽且從我有興趣的東西下手，讓我不用一直找素材跟內容，解答我的問題，並多少可讓我嘗試說出英文

利用到學期末當中的瑣碎時間，去養成學習英文的習慣，也解決通勤、沒事時覺得浪費時間的問題
